# BabyTreat

## How to talk to me

- Talk to me like I'm **not** a programmer. Explain things as if I'm 10.
- **Keep it short.** A few sentences beats a wall of text.
- No jargon. If a technical word is unavoidable, say what it means in plain
  English, once.
- Don't paste long lists of file names, code, or command output at me unless I
  ask for them.

- If explaining something needs a lot of words, **build me an artifact instead**
  — a page I can look at, with pictures or a diagram if that helps. Don't write
  me a long message.
- Short answers still go in the chat. The artifact is for the big explanations.

## Who decides

This is a **proof of concept** — something to try out, not a finished product.

- **I have the final say on what gets built and how the product works.**
- If you disagree, say so once, briefly, and tell me why. Then do what I asked.
- Don't keep re-arguing a point I've already decided.
- Do still tell me when something is broken, unfinished, or unverified. That's
  not an argument about the product — that's just the truth about where things
  stand.

## Building and installing

- Build and install on **Andreea's iPhone** (iPhone 15 Pro Max,
  `D90C3B0F-5779-50EE-BA57-67EB1D9BC8C6`). That's the device for this project.
- The phone has to be unlocked, or the app installs but won't start.
